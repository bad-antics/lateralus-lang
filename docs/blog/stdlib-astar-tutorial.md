# A* Heuristic Search Algorithm in Lateralus

## 1. Introduction

Pathfinding across spatial topologies, grid worlds, and complex graphs is a core challenge in computer science, robotics, and artificial intelligence. While **Dijkstra's Algorithm** guarantees the shortest path by exploring outward uniformly in all directions ($O(V \log V + E)$), it examines vast numbers of irrelevant nodes away from the target. Conversely, **Greedy Best-First Search** charges aggressively toward the goal guided solely by a heuristic, but often falls into local minima or produces suboptimal detours.

Formulated by Peter Hart, Nils Nilsson, and Bertram Raphael at Stanford Research Institute in 1968, the **A\* Search Algorithm** achieves the optimal balance by synthesizing both approaches into a unified evaluation function:

$$f(n) = g(n) + h(n)$$

where:
- **$g(n)$**: The exact accumulated path cost from the start node to node $n$.
- **$h(n)$**: The estimated heuristic cost from node $n$ to the goal.
- **$f(n)$**: The total estimated cost of the cheapest solution passing through $n$.

When the heuristic $h(n)$ is **admissible** (never overestimating the true cost to reach the goal, $h(n) \le h^*(n)$), A\* is mathematically guaranteed to return the **strictly optimal shortest path**!

This tutorial presents an implementation of the A\* search algorithm in Lateralus (`stdlib/astar.ltl`), including warehouse robot pathfinding and golden test vectors.

## 2. Core Heuristic Theory & Guarantees

### 2.1 Admissibility & Consistency
1. **Admissibility**:
   $$h(n) \le h^*(n) \quad \forall n$$
   If $h$ never overestimates the true remaining distance, A\* with tree search is guaranteed to find an optimal path.
2. **Consistency (Monotonicity)**:
   For every node $u$ and every successor $v$ of $u$ generated by an action with cost $c(u, v)$:
   $$h(u) \le c(u, v) + h(v)$$
   Consistency implies the triangle inequality. If $h$ is consistent, the sequence of $f$-scores along any path is non-decreasing, and when A\* selects a node for expansion, its $g$-score is already optimal—meaning nodes never need to be reopened!

### 2.2 Manhattan Distance ($L_1$ Norm)
On a 4-connected grid (Up, Down, Left, Right movement with unit edge cost 1):

$$h(\text{cell}_1, \text{cell}_2) = |r_1 - r_2| + |c_1 - c_2|$$

The Manhattan distance represents the exact shortest path between two cells in the absence of obstacles, making it both **admissible** and **consistent**.

## 3. Lateralus Implementation

Here is the complete implementation in Lateralus:

```lateralus
fn abs_val(x) {
    if x < 0 {
        return 0 - x
    }
    return x
}

fn manhattan(r1, c1, r2, c2) {
    return abs_val(r1 - r2) + abs_val(c1 - c2)
}

fn contains_node(arr, node) {
    let i = 0
    while i < len(arr) {
        if arr[i] == node {
            return true
        }
        i = i + 1
    }
    return false
}

pub fn astar_search(grid, rows, cols, sr, sc, gr, gc) {
    let start = sr * cols + sc
    let goal = gr * cols + gc

    if sr == gr and sc == gc {
        return [start]
    }

    if grid[sr][sc] == 1 or grid[gr][gc] == 1 {
        return []
    }

    let g_score = dict()
    let f_score = dict()
    let closed_set = dict()
    let came_from = dict()

    let r = 0
    while r < rows {
        let c = 0
        while c < cols {
            let idx = r * cols + c
            g_score[idx] = 999999999
            f_score[idx] = 999999999
            closed_set[idx] = false
            c = c + 1
        }
        r = r + 1
    }

    g_score[start] = 0
    f_score[start] = manhattan(sr, sc, gr, gc)

    let open_set = [start]

    while len(open_set) > 0 {
        let best_f = 999999999
        let best_idx = 0
        let i = 0
        while i < len(open_set) {
            let node = open_set[i]
            if f_score[node] < best_f {
                best_f = f_score[node]
                best_idx = i
            }
            i = i + 1
        }

        let current = open_set[best_idx]

        if current == goal {
            let path = [goal]
            let curr = goal
            while curr != start {
                curr = came_from[curr]
                path = push(path, curr)
            }
            let rev_path = []
            let k = len(path) - 1
            while k >= 0 {
                rev_path = push(rev_path, path[k])
                k = k - 1
            }
            return rev_path
        }

        let next_open = []
        let j = 0
        while j < len(open_set) {
            if j != best_idx {
                next_open = push(next_open, open_set[j])
            }
            j = j + 1
        }
        open_set = next_open
        closed_set[current] = true

        let cur_r = idiv(current, cols)
        let cur_c = current % cols

        let dr = [-1, 1, 0, 0]
        let dc = [0, 0, -1, 1]
        let dir = 0
        while dir < 4 {
            let nr = cur_r + dr[dir]
            let nc = cur_c + dc[dir]

            if nr >= 0 and nr < rows and nc >= 0 and nc < cols {
                let n_idx = nr * cols + nc
                if grid[nr][nc] == 0 and not closed_set[n_idx] {
                    let tentative_g = g_score[current] + 1
                    if tentative_g < g_score[n_idx] {
                        came_from[n_idx] = current
                        g_score[n_idx] = tentative_g
                        f_score[n_idx] = tentative_g + manhattan(nr, nc, gr, gc)
                        if not contains_node(open_set, n_idx) {
                            open_set = push(open_set, n_idx)
                        }
                    }
                }
            }
            dir = dir + 1
        }
    }

    return []
}
```

## 4. Real-World Applications

1. **Autonomous Warehouse AGVs & Robotics**: Guiding autonomous mobile robots (AMRs) through dynamic fulfillment distribution centers while evading static shelves and active forklifts.
2. **Game AI & Navmesh Routing**: Directing non-player characters (NPCs) along optimal paths in strategy games and 3D virtual environments.
3. **Printed Circuit Board (PCB) Trace Routing**: Routing conductive copper traces between microchip pins without trace crossovers.
4. **Autonomous Vehicle Navigation**: Planning road trajectories with turn penalties and traffic lane constraints.
